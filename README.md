# SettleUp Lite

A minimal Flutter app for splitting group expenses, generating UPI payment links, rendering QR codes, and sharing settlements.

## Features

- Enter a total bill amount
- Add multiple people and owed amounts
- Generate UPI deep links for each person
- Render QR codes for quick UPI scanning
- Share the complete settlement using the system share sheet

## Run

1. Install Flutter stable and ensure `flutter` is on your `PATH`.
2. From this directory, run:

```bash
flutter pub get
flutter run
```

If you want Flutter to generate any missing platform scaffolding for your environment, run:

```bash
flutter create .
```
